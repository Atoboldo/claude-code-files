# Claude Code Files

A collection of files and experiments using [Claude Code](https://claude.ai/code) — Anthropic's official CLI for Claude.

## Getting Started

1. Install Claude Code: `npm install -g @anthropic-ai/claude-code`
2. Clone this repository
3. Run `claude` inside the project folder

## Usage

Add your Claude Code projects, scripts, and experiments here.
